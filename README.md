# Projeto-Integrador
> **InsertV** 

O Projeto-Integrador(P.I) é um projeto desenvolvido ao longo do segundo semestre de 2026 por estudantes da Fatec do curso de Desenvolvimento de Software Multiplataforma.

# InsertV
Nossa ideia foi criar um site que tem como objetivo a divulgação e candidatura de vagas, parecido com Linkdedin e o Infojobs, o diferencial dele será maior chances de efetivação de vagas para pessoas inexperientes de tais funções ou para jovens que estão ingressando no mercado de trabalho, dando opções também para cursos de qualificações para maior chance de contratação e efetivação.
