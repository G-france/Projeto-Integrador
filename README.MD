# Projeto Integrador

> **InsertV**

O Projeto Integrador(P.I.) é um projeto desenvolvido ao longo do segundo semestre de 2026 por estudantes da Fatec Diadema do curso de Desenvolvimento de Software Multiplataforma.

# InsertV
Nossa ideia foi criar um site que tem como o objetivo a divulgação e candidatura de vagas, semelhante com o Linkdedin e o Infojobs, o diferencial dele será maiores chances de efetivação de vagas para pessoas inexperientes de tais funções ou para jovens que buscam ingressar no mercado de trabalho, dando também cursos de qualificações para maior chance de contratação e efetivação;

# Tecnologias utilizadas

* 🌐 **HTML**
* 🎨 **CSS**
* 📜 **JavaScript**
* 🗄️ **MySQL**
